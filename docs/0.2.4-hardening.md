# 0.2.4 hardening

Recommended fixes from the 0.2.3 audit. Implement in this order. Do not rebuild the Settings tab, do not dump more category synonyms, and do not reorder security vs skill.

| # | Problem | Recommendation | This release |
| --- | --- | --- | --- |
| 1 | Cache write failure drops a valid in-memory catalog | Admit the catalog, keep `cache-write-failed` as a non-fatal error | Yes |
| 2 | `catalogUrl` schema default is `''` | Default to the GitHub Pages catalog URL | Yes |
| 3 | Each keystroke hits Host; each field compiles a new RegExp | Debounce the Host query 250ms; compile one matcher per word | Yes |
| 4 | One-character CJK queries substring-match too widely | A single CJK character matches only an exact field, not a substring | Yes |
| 5 | Search placeholder hides category-label search | Mention category names in the placeholder | Yes |
| 6 | Installed view ignores the search box | Show search on Installed; filter with `marketplaceTextsMatchQuery` | Yes |
| 7 | Agent search returns 10 rows; category enum is a second list | Limit 20; enum from `MARKETPLACE_CATEGORY_PRIORITY` | Yes |
| 8 | Patch/README omit `agentTools` | Restate `agentTools: true` in the patch and config examples | Yes |
| 9 | `package.json` `files` omits `README.zh-CN.md` | Add it | Yes |
| 10 | `.strict()` catalog schema rejects a newer scanner field | `.passthrough()` so unknown keys survive digest verification | Yes |
| 11 | No CI gate on the live catalog | `scripts/check-live-catalog.mjs` in CI (size + parse) | Yes |
| 12 | Same-origin 403 when `Origin` is missing | Allow when `Sec-Fetch-Site: same-origin` | Yes |
| 13 | Daily snapshot / single GitHub Pages URL | Document it; a failed scan already leaves the last Pages deploy | Docs only |
| 14 | ~1600 uncategorized; skill vs security collisions | Leave conservative tokens and current priority | No |
| 15 | Settings tab size | Split only when a new user path lands | No |
